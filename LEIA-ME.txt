CLÍNICA SIMPLES — COMO USAR

1. Leia Projeto_Clinica.pdf. O .md é editável; o .html abre no navegador.
2. Preencha nomes completos e RGMs. As datas de sprints são propostas, não histórico real.
3. São exatamente 15 itens da lista do PDF: 1, 2, 3, 4, 5, 25, 26, 31, 32, 33, 34, 35, 36, 40 e 42.

EXECUTAR NO WINDOWS / VS CODE
É necessário Node.js 22.13 ou superior (testado com Node.js 24.22.1).
Abra a pasta clinica no VS Code e abra Terminal > Novo Terminal.
Execute:
  node main.js
Ou:
  npm start
Não precisa de npm install: o programa usa apenas módulos nativos do Node.js.
Para conferir sua versão: node --version
Se node não for reconhecido, instale o Node.js e reabra o terminal.

TESTES
Dentro da pasta clinica:
  npm test
Ou:
  node --test test_main.js

O banco clinica.db nasce vazio ao executar e fica ao lado de main.js.
O programa salva cada operação e mantém os dados ao fechar.
Para a apresentação, use somente dados fictícios. Exemplo de CPF de teste
com formato aceito pelo protótipo: 00000000001. Não representa validação real.
CRM fictício de demonstração: TESTE/SP.
Datas: AAAA-MM-DD. Horários: AAAA-MM-DD HH:MM. Valores: 150,00.

DEMONSTRAÇÃO
1) Opção 1: cadastrar paciente fictício.
2) Opção 2: cadastrar médico fictício.
3) Opção 3: anotar os códigos.
4) Opção 4: agendar com esses códigos.
5) Opção 5: anotar código do agendamento.
6) Opção 7: realizar consulta com queixa, diagnóstico e conduta fictícios.
7) Opção 8: ver histórico e código da consulta.
8) Opção 9: registrar R$ 150,00 como Pendente, forma PIX.
9) Opção 13: conferir pendência; opção 10: obter código do pagamento.
10) Opção 11: baixar o pagamento (usa a data atual).
11) Opção 12: consultar um período que inclua a data de recebimento.
12) Opção 0: sair.

LIMITES E VERIFICAÇÃO
Sem login, interface gráfica, integração bancária ou módulos fora dos 15 itens.
Não há edição/exclusão geral. O horário da consulta é o horário agendado.
O CPF é normalizado, tem 11 dígitos e é único, sem cálculo de verificadores.
O sistema trata cada pagamento como uma parcela; não calcula saldo de cobrança.
Os 10 testes automatizados da versão JavaScript passaram com Node.js 24.22.1.
Incluem regras, as 14 opções do menu, execução real e persistência ao reabrir.
